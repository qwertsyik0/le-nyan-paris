# Le Nyan Paris

Отдельный статический сайт события **Le Nyan Paris**.

## Ссылка после включения GitHub Pages

```text
https://qwertsyik0.github.io/le-nyan-paris/
```

## Структура

```text
index.html       главная страница
styles.css       дворцовый визуальный стиль
script.js        плавное появление блоков и якорная навигация
assets/          фавикон и превью
404.html         запасная страница
.nojekyll        отключение Jekyll
```

## Как включить GitHub Pages

1. Открыть репозиторий `qwertsyik0/le-nyan-paris`.
2. Settings → Pages.
3. Source: `Deploy from a branch`.
4. Branch: `main`.
5. Folder: `/root`.
6. Save.

После этого сайт появится по адресу:

```text
https://qwertsyik0.github.io/le-nyan-paris/
```
